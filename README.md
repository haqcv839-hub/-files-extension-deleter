# -files-extension-deleter/删除指定后缀的文件
第一步：解压并运行 Thonny

把下载好的压缩包解压，双击运行里面的 Thonny.exe 打开编辑器。

第二步：复制绝对路径

打开电脑的“文件资源管理器”，进到你要删除文件的那个文件夹。点击顶部地址栏，直接复制这一串绝对路径（例如：C:\Users\Administrator\Desktop\目标文件夹）。

第三步：在 Thonny 中运行并输入

在 Thonny 里点击运行按钮（绿色的播放键），并在下方的控制台按照提示输入：

文件路径：直接粘贴刚才复制的绝对路径。

需要删除的文件后缀：输入你想删的后缀（例如：.txt）。
📝 Step-by-Step Guide for the Script
Step 1: Open and Unzip Thonny

Unzip the downloaded file and run Thonny.exe to launch the code editor.

Step 2: Copy the Absolute Path

Open Windows File Explorer, navigate to your target folder, and click on the address bar at the top to copy the absolute path (e.g., C:\Users\Administrator\Desktop\TargetFolder).

Step 3: Run the Script and Input Details

Run the script in Thonny and provide the required inputs in English when prompted:

File Path: Paste the absolute path you just copied.

File Extension to Remove: Type the extension you want to delete (e.g., .txt).
